# Routine Dashboard

スマホやPCのブラウザで使える、シンプルな習慣管理ダッシュボードです。

カテゴリ・タスク・実施曜日を自由に設定し、毎日の達成状況を **○ / △ / ×** で記録できます。
アプリのインストールや会員登録は不要です。


## Features

* 今日やるタスクを自動表示
* 曜日に応じたタスク表示
* タスクごとの達成状況を記録
* ○ / △ / × によるシンプルな入力
* 今日の達成率を自動計算
* 1週間の達成率を表示
* 過去の日別記録を編集
* カテゴリの追加・削除・編集
* タスクの追加・削除・編集
* タスクごとの実施曜日設定
* カテゴリごとのSVGアイコン設定
* カテゴリカラー設定
* JSON形式でのバックアップ・復元
* スマホ表示に最適化したUI

## How to Use

### 1. 今日のタスクを確認する

画面上部の **「今日やること」** に、その日に実施予定のタスクが表示されます。

各タスクの右側にあるボタンから、達成状況を選択します。

| 記号 | 意味     |
| -- | ------ |
| ○  | できた    |
| △  | 少しできた  |
| ×  | できなかった |

入力すると、達成率が自動で更新されます。

### 2. 1週間の記録を見る

**「1週間の記録」** では、週ごとの達成率を確認できます。

前週・次週ボタンで、別の週の記録も表示できます。

### 3. 過去の日付を編集する

入力し忘れた日や、あとから修正したい日がある場合は、
**「日別記録を編集」** から日付を選んで編集できます。

### 4. カテゴリ・タスクをカスタマイズする

**「カテゴリ・タスク設計」** から、以下を自由に変更できます。

* カテゴリ名
* カテゴリの目標
* カテゴリのアイコン
* カテゴリの色
* タスク名
* タスクを実施する曜日
* カテゴリやタスクの追加・削除

設定した内容は、ブラウザ内に保存されます。

## Data Storage

このダッシュボードは、入力されたデータをサーバーには送信しません。
記録や設定は、ブラウザの `localStorage` に保存されます。

そのため、基本的には利用者本人の端末内でデータが管理されます。

ただし、以下の場合は記録が消える可能性があります。

* ブラウザの履歴やWebサイトデータを削除した場合
* プライベートブラウズで使用した場合
* 別のブラウザで開いた場合
* 端末を変更した場合
* URLが変わった場合

長く使う場合は、定期的に **JSONバックアップ** を保存することをおすすめします。

## Backup and Restore

画面下部の **「バックアップ」** から、記録と設定をJSONファイルとして保存できます。

保存したJSONファイルは、あとから読み込むことで復元できます。

## Recommended Environment

* iPhone：Safari
* Android：Chrome
* PC：Chrome / Edge / Safari

スマホで使う場合は、SafariやChromeで開いて、ホーム画面に追加するとアプリのように使えます。

## Deploy with GitHub Pages

このHTMLは静的ファイルのみで動作するため、GitHub Pagesにそのまま配置できます。

### 手順

1. このリポジトリに `index.html` を配置する
2. GitHubのリポジトリ設定を開く
3. **Settings > Pages** に移動する
4. Sourceを **Deploy from a branch** にする
5. Branchを `main`、Folderを `/root` にする
6. 発行されたURLにアクセスする
