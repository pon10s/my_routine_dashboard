# Routine Dashboard

スマホやPCのブラウザで使える、シンプルな習慣管理ダッシュボードです。

カテゴリ・タスク・実施曜日を自由に設定し、毎日の達成状況を **○ / △ / ×** で記録できます。  
アプリのインストールや会員登録は不要です。

## Concept

このダッシュボードでは、タスクを以下の2種類に分けて扱います。

### 通常タスク

カテゴリ・タスク設定で登録する、繰り返し行う習慣タスクです。

例：

- 単語30個
- 20分ウォーキング
- ジムに行く
- 本を10ページ読む

### 臨時タスク

その日だけ追加したいタスクです。

例：

- 病院に行く
- 部屋を片付ける
- 旅行の準備をする
- GitHub Pagesを更新する

臨時タスクは、その日だけのタスクとして記録されます。  
通常のカテゴリ・タスク設定には追加されません。

## How to Use

### 1. 今日のタスクを確認する

画面上部の **「今日やること」** に、その日に実施予定のタスクが表示されます。

各タスクの右側にあるボタンから、達成状況を選択します。

| 記号 | 意味 |
|---|---|
| ○ | できた |
| △ | 少しできた |
| × | できなかった |

入力すると、今日の達成率が自動で更新されます。

### 2. タスクを追加する

**「タスクを追加」** から、その日だけのタスクを追加できます。

追加方法は2種類あります。

#### 既存タスクから追加

カテゴリ・タスク設定に登録されているタスクから選んで、その日だけ追加できます。

#### その他を入力

自由入力で、その日だけの臨時タスクを追加できます。

その他タスクは、グレー系の色と専用アイコンで表示されます。

### 3. タスクを削除する

今日のタスクや、過去の日別タスクは削除できます。

タスクカードを左にスワイプすると、削除確認のポップアップが表示されます。

- OK：タスクを削除
- キャンセル：削除せず、カード位置を元に戻す

確認中は、どのカードを削除しようとしているか分かるように、カードが左にずれた状態で表示されます。

### 4. 1週間の記録を見る

**「1週間の記録」** では、週ごとの達成率を確認できます。

週の集計は、**月曜始まり・日曜終わり** です。

前週・次週ボタンで、別の週の記録も表示できます。

### 5. 過去の日別記録を編集する

1週間の記録に表示されている日付カードをタップすると、その日のタスク一覧が開きます。

開いた状態で、以下の操作ができます。

- ○ / △ / × の変更
- タスクの追加
- タスクの削除

もう一度日付カードをタップすると、編集欄を閉じられます。

## Category and Task Settings

**「カテゴリ・タスク設定」** から、ルーティンの内容を自由に変更できます。

変更できる項目は以下です。

- カテゴリ名
- カテゴリの目標
- カテゴリのアイコン
- カテゴリの色
- タスク名
- タスクを実施する曜日
- カテゴリの追加・削除
- タスクの追加・削除

カテゴリは折りたたみ式になっており、カテゴリをタップすると詳細設定が開きます。

## Reset Options

カテゴリ・タスク設定には、2種類のリセット機能があります。

### 初期設定に戻す

サンプルのカテゴリ・タスク設定に戻します。

記録も含めてサンプル状態に戻したい場合に使用します。

### 内容を全てリセットする

カテゴリ、タスク、記録をすべて削除します。

まっさらな状態から自分で設定したい場合に使用します。

## Snapshot System

このダッシュボードでは、日別スナップショット方式を採用しています。

### 日別スナップショットとは

各日付ごとに、その日に表示されたタスク一覧を保存する仕組みです。

これにより、あとからカテゴリ・タスク・曜日設定を変更しても、過去の記録が壊れにくくなります。

### 例

最初は以下の設定だったとします。

```text
火曜：20分ウォーキング
水曜：なし
```

火曜にウォーキングを記録したあと、設定を変更します。

```text
火曜：なし
水曜：20分ウォーキング
```

この場合でも、過去の火曜の記録にはウォーキングが残ります。  
過去の水曜に、後からウォーキングが勝手に追加されることもありません。

## Reflection Rules

カテゴリ・タスク設定の変更は、基本的に **今日以降** に反映されます。

### 今日以降

最新のカテゴリ・タスク設定に基づいて表示されます。

### 過去

すでにスナップショットがある日付は、その日のスナップショットを使います。  
現在の設定変更は、過去の記録には自動反映されません。

### スナップショットがない過去日

その日を開いた時点の現在設定から、日別スナップショットを作成します。

## Achievement Rate

達成率は、日別スナップショットに含まれるタスクをもとに計算されます。

スコアは以下の通りです。

```text
○ = 1点
△ = 0.5点
× = 0点
未入力 = 0点
```

### 日別達成率

```text
日別達成率 = 取得点数 ÷ その日のタスク数
```

### 週別達成率

```text
週別達成率 = 月曜〜日曜の取得点数合計 ÷ 月曜〜日曜のタスク数合計
```

## Data Storage

このダッシュボードは、入力されたデータをサーバーには送信しません。  
記録や設定は、ブラウザの `localStorage` に保存されます。

そのため、基本的には利用者本人の端末内でデータが管理されます。

ただし、以下の場合は記録が消える可能性があります。

- ブラウザの履歴やWebサイトデータを削除した場合
- プライベートブラウズで使用した場合
- 別のブラウザで開いた場合
- 端末を変更した場合
- URLが変わった場合

長く使う場合は、定期的に **JSONバックアップ** を保存することをおすすめします。

## Backup and Restore

画面下部の **「バックアップ」** から、記録と設定をJSONファイルとして保存できます。

バックアップには以下が含まれます。

- 現在のカテゴリ・タスク設定
- 日別スナップショット
- 日別実績
- 臨時タスク
- 記録データ

保存したJSONファイルは、あとから読み込むことで復元できます。

## Recommended Environment

- iPhone：Safari
- Android：Chrome
- PC：Chrome / Edge / Safari

スマホで使う場合は、SafariやChromeで開いて、ホーム画面に追加するとアプリのように使えます。

## Notes

このプロジェクトは、個人の習慣管理や目標管理を目的としたシンプルなダッシュボードです。  
医療・健康・投資などに関する専門的な判断を代替するものではありません。
